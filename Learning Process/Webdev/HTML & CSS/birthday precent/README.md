<h2>🎂 Birthday Present Page</h2>

<h4>A small birthday gift page built with only HTML and CSS. 🎁</h4>
<h4>It shows a greeting, a photo, and five gift boxes that reveal a surprise image when you hover over them.</h4>

<h3>✨ Features</h3>

<h4>🎁 Gift boxes that change to a new image on hover</h4>
<h4>🌈 Soft gradient background</h4>
<h4>🖼️ Round photo with a colored border</h4>
<h4>💌 Birthday message with a link at the bottom</h4>

<h3>🛠️ HTML Used</h3>

<h4>🧱 Page structure with div, headings, paragraphs, and images</h4>
<h4>🔗 Link that opens in a new tab</h4>
<h4>🔤 Google Fonts linked in the head</h4>
<h4>♿ Alt text on images</h4>

<h3>💅 CSS Used</h3>

<h4>🔤 Font family: Happy Monkey from Google Fonts</h4>
<h4>🌈 Gradient background using linear-gradient</h4>
<h4>📐 Flexbox with flex-direction: column and align-items: center</h4>
<h4>🌟 Text shadow on headings and text</h4>
<h4>🖼️ Background images with background-size: cover</h4>
<h4>🖱️ Hover effect to swap the gift images</h4>
<h4>🔘 Border, border-radius, padding, and margin</h4>

<h3>📁 Files</h3>

<h4>📄 index.html: the page structure</h4>
<h4>🎨 style.css: all the styling</h4>
<h4>🖼️ images: the pictures used on the page</h4>

<h4>Made with love using HTML and CSS 💻✨</h4>
